# Как внести свой вклад в проект

## Процесс работы
1. Создайте ветку от актуального `main`: `git checkout -b feature/название-задачи`.
2. Внесите изменения и сделайте коммит: `git commit -m "Описание изменений"`.
3. Отправьте ветку на GitHub: `git push origin feature/название-задачи`.
4. Создайте Pull Request (PR) в ветку `main`.
5. Дождитесь проверки кода (Code Review) от другого участника команды.
6. После получения Approve и прохождения CI (тесты) выполните Squash and merge.

## Правила
- Прямой пуш в `main` запрещен.
- Один PR = одна задача.
- Код должен проходить `flutter analyze` и `flutter test`.
